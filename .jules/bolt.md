## 2026-09-26 - Parallelizing Gradio API Batch Requests & Eliminating Render-Phase DOM Reflows
**Learning:** Sequential `await client.predict()` in loops for batch generations (e.g., `batchCount` = 2 or 4) creates linear latency scaling ($O(N)$), causing multi-image requests to take 30-60+ seconds. Executing batch prediction requests in parallel with `Promise.all()` reduces total latency by up to 50-75%. Furthermore, accessing DOM ref properties like `ref.current.clientWidth` during React component render causes layout thrashing and forced DOM reflows on every frame; replacing ref reads in render with a `ResizeObserver` eliminates unnecessary browser layout recalculations.
**Action:** Use `Promise.all()` for batch Gradio predict calls, and use `ResizeObserver` instead of reading DOM refs during render.
