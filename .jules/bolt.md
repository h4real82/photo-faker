## 2026-09-23 - Batch Model Inference Parallelization & Split Slider Throttling
**Learning:** Sequential `await` in loops when generating batch AI images via `@gradio/client` multiplied server-side latency by $N$ (the batch size). Replacing sequential awaits with `Promise.allSettled` parallelizes batch inference, dramatically cutting batch latency from $O(N \cdot T)$ to $\sim O(T)$. On the frontend, tracking element layout width via `ResizeObserver` instead of reading `.clientWidth` during render avoids React ref-access-during-render errors and layout thrashing, while `requestAnimationFrame` prevents drag event flood re-renders.
**Action:** Always parallelize independent outbound AI model calls using `Promise.allSettled` and use `ResizeObserver` + `requestAnimationFrame` for interactive split-sliders.
